# 🏆 World Cup Simulator 2026

An object-oriented FIFA World Cup 2026 simulator developed in Python.

## 📖 Overview

This project simulates the complete FIFA World Cup tournament, including:

- Team loading from a CSV dataset
- Automatic seeding based on FIFA rankings
- Random group draw
- Group stage simulation
- Knockout stage simulation
- Extra time and penalty shootouts
- Tournament statistics
- Championship probability estimation using Monte Carlo simulation
- Championship probability visualization with Matplotlib

The project was developed using Object-Oriented Programming (OOP) principles.

## ▶️ Running the Project

Run:

```bash
python simulator_worldcup.py
```

Then choose one of the menu options:

1. Load teams
2. Draw groups
3. Simulate group stage
4. Simulate full tournament
5. Run Monte Carlo simulations
6. Display knockout bracket
7. Exit
